# Python Fibonacci Series

## About

This project contains a Python program, `fibonacci.py`, that generates a Fibonacci series for a specified number of terms.

The program uses a `for` loop and updates two variables to generate the sequence.

## File Structure

```text
python-beginner/
└── fibonacci.py
```

## How to Run

### Prerequisites

* Python 3 installed on your computer.

### Steps

1. Download or clone the repository.
2. Open a terminal in the project directory.
3. Run the following command:

```bash
python fibonacci.py
```

Alternatively, use:

```bash
python3 fibonacci.py
```

4. Enter the number of terms when prompted.

## Learning Objectives

This program helps beginners understand:

* User input using `input()`.
* Type conversion using `int()`.
* Variables and multiple assignment.
* Iteration using a `for` loop.
* Generating a sequence using addition.
* Displaying output using `print()`.

## Concept

The Fibonacci series is a sequence in which each number is the sum of the previous two numbers.

The sequence begins:

```text
0, 1, 1, 2, 3, 5, 8, 13, ...
```

## Purpose

This project helps beginners practise loops, arithmetic operations, variable updates, and sequence generation in Python.
